# Bộ lệnh ngắn — AI Cooking Master Video

Dùng các câu ngắn sau để điều khiển SKILL trong lúc làm:

- **"Gợi ý 5 món"** → chạy Phase 1 (đề xuất món + câu dẫn mẫu).
- **"Chọn món [số/tên]"** → chốt món, sang Phase 2 chia cảnh.
- **"Chia cảnh + viết lời dẫn"** → Phase 2 + 2B (storyboard kèm lời dẫn tiếng Việt từng cảnh).
- **"Làm prompt ảnh"** → Phase 3 (JSON từng cảnh).
- **"Làm prompt video"** → Phase 4 (JSON + narration_vi + voice_dna + asmr_sound + narration_timing).
- **"Làm SEO + thumbnail"** → Phase 5 theo Master Prompt gốc.
- **"Làm poster File 02, SEO File 03"** → poster 1 code block + lời dặn dò; SEO đúng 5 khối.
- **"Render luôn"** → render video (tối đa 6 cảnh/lượt), upscale, ráp, QC.
- **"Render tiếp"** → render các cảnh còn lại của dự án đang dở.
- **"Giao phim"** → upload bản gốc lên Google Drive và gửi link.
- **"Đổi giọng [ấm ASMR / nam trầm]"** → đổi Voice DNA (chỉ đổi trước Phase 2B; đổi giữa chừng phải làm lại lời dẫn + render).
